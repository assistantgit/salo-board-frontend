## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## 🛠 Линтинг и форматирование

В проекте используется [Biome](https://biomejs.dev/) для быстрого форматирования и проверки кода.

```bash
# Проверка кода и исправление простых ошибок
npm run check

# Только форматирование
npm run format

# Проверка типов
npm run type-check
```

Также настроен **Husky** для автоматической проверки кода при каждом коміте.
